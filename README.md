# Lico 力扣手撕辅导 Agent

一只上发条的木偶蜜蜂 🐝「lico」，陪你手撕力扣算法。  
配置 Key → 听题/朗读 → 形象讲解（**逐段**）+金句 → **抄写**+分步敲代码+审查 → **默写板**整题默写 → 全程轨迹留存 → **平行时空**回看旧题。

## 给使用者的快速说明

**需要：** 一台 Windows 电脑 + 已安装 Python 3.10 及以上（安装时勾选 “Add python.exe to PATH”）。  
**不需要：** 任何编程知识、服务器、账号。

### 三步开始
1. 把整个 `lico-leetcode-agent-main` 文件夹拷到任意位置（桌面也行）。
2. **双击 `start.bat`**。首次会自动装好运行环境（几十秒），之后秒开。
3. 浏览器自动打开 `http://127.0.0.1:8000`。按提示填入你**自己的** DeepSeek Key，点击「上发条」即可开始。

> ⚠️ 关于 Key：Key 只保存在你本机数据库里，**不会上传给任何人**。本项目源码中不含任何 Key。
>
> 💡 也可从 GitHub 获取最新版：https://github.com/zouchuheiye/lico-leetcode-agent

### 不填 Key 也能看效果
即使不填 Key，也能用内置离线题库跑通完整流程（第 1 题「两数之和」为完整离线内容），适合先看演示。

## 核心玩法

- **听题 / 朗读**：蜜蜂朗读题目与讲解，开车路上也能听。
- **逐段讲解 + 金句**：长讲解拆成小段，逐段听、可回看，每段配一句记忆金句，听累了也能分段消化。
- **抄写 + 敲码**：讲解阶段可直接在页面里**抄写**代码加深印象；敲码阶段独立默写，提交后由 AI 审查。
- **默写板（整题默写）**：从「已做题集」进入，把整道题遮住重写一遍；**本地实时保存草稿**，切页/来回切换不丢内容。
- **全程轨迹留存**：每题的讲解、分解、每步代码、每次审查结论都记录下来，复习可看原始过程。
- **平行时空线**：在学习轨迹里「穿越」回任意一道旧题重新复习，**不受当前题阻拦**；旧题复习只落「抄写」记录、敲码仅在本地，不污染主进度。右上角「⏱ 回到现在」一键回到当前题。

## 常见问题
- **端口 8000 被占用**：关掉占用 8000 的程序，或改 `start.bat` 最后一行 `--port 8000` 为其他端口。
- **想换模型标识**：编辑 `backend/config.py` 里的 `DEEPSEEK_MODEL`。
- **数据在哪**：所有学习记录存在 `backend/lico.db`（SQLite）。删掉它即回到初始状态。
- **听题没声音**：Windows 设置 → 时间和语言 → 语音 → 添加中文（简体）语音包，重启浏览器即可。
- **想复习旧题**：进「学习轨迹」点任意一题即可；复习中途想回当前题，点右上角「⏱ 回到现在」。

## 技术备注（给技术同学）
- 前后端分离：FastAPI 提供 REST 接口并托管前端静态文件。
- 存储层永久保存所有学习轨迹（讲解、分解、每步代码、每次审查结论），复习可看原始过程。
- 断点续学：中断后下次进入从该题中断处继续；只有整题通过才标记「已学完」。
- 平行时空：复习旧题的写操作均按 `problem_id` 定位，不依赖全局「当前题」，故主进度与复习互不影响；复习接口为只读聚合 `GET /api/learn/problem/{id}`。
